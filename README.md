# MicDrop 🎤

A web app for practicing speaking with instant feedback and confidence tracking.

## Why this exists
Speaking can be stressful — MicDrop is designed to make practice feel low-pressure and consistent through small, trackable sessions.

## Features
- Practice prompts and guided speaking sessions
- Feedback on phrasing and word choice (AI-assisted)
- Confidence / progress stats over time
- Vocabulary saving (personal mini-dictionary)

## Tech Stack
- Front end: React, TypeScript
- Styling: Tailwind CSS
- AI: Gemini API
